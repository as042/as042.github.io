# as042.github.io

My homepage, served by GitHub Pages at https://as042.github.io/.

Plain static HTML (no Jekyll; see `.nojekyll`).

- `index.html`: page content. Replace the placeholder text.
- `style.css`: styling (light and dark mode).
- `assets/`: headshot (`profile.jpg`) and CV (`cv.pdf`).

Preview locally with `python3 -m http.server` and open http://localhost:8000.
